What is a "session" in your model?

Today each bot has one continuous history (one JSONL file keyed bot:<id>). Your description says "bot names → sessions" (plural), so I want to confirm what a session is before I design around it. Each option below is a literal sketch of how the sidebar tree would look.

One session per bot · label = current lesson

Sidebar lists each bot once. The bot row shows the current/latest lesson topic as a sub-label, auto-generated from the conversation.
